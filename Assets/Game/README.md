# Service Post — проект тестового задания

Unity 6000.3.5f2, URP, Input System, Cinemachine. Основная сцена — `Assets/Game/Scenes/ServicePost.unity`; она включена в Build Settings.

- `SubmissionREADME.md` — управление, содержание задания и короткий маршрут прохождения.
- `DesignerGuide.md` — настройка взаимодействий, диалогов, лестницы, дверей и лифта в Inspector.
- `Editor/*Editor.cs` — специализированные инспекторы с подсказками и проверкой обязательных ссылок.

Все игровые ассеты сцены созданы в проекте. Odin и EvoInfrastructure для запуска не нужны.
