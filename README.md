# Сервисный пост

Игровой прототип для тестового задания Technical Level Designer в изометрической RPG. Проект сделан в Unity 6000.3.5f2 на URP, Input System и Cinemachine.

## Быстро посмотреть

1. Скачайте [Windows-билд](https://drive.google.com/drive/folders/1ENfQq_g6sNxjd8qpgoUtiNVW_Es4UR2t) и распакуйте `ServicePost_Windows.zip`.
2. Запустите `ServicePost.exe`. Управление: WASD — движение, Shift — бег, E — взаимодействие, стрелки/W/S — выбор в меню, Enter — подтверждение, Esc — выход из меню.
3. Поговорите с техником, откройте проход, проверьте лестницу и лифт, включите питание и активируйте терминал в аппаратной. Прохождение занимает около 3–5 минут.

## Открыть проект

Откройте корень репозитория в Unity 6000.3.5f2, затем сцену [`Assets/Game/Scenes/ServicePost.unity`](Assets/Game/Scenes/ServicePost.unity). Она также назначена стартовой в Build Settings. Внешние платные ассеты, Odin и EvoInfrastructure не требуются.
